# Blockfall

**Name the flag. Drop the block.**

An original falling-block puzzle game where every piece is a different country's flag (196 countries, no repeats until all have appeared). Each new piece hovers at the top until you **say the country's name out loud**, and only then can it drop. Faster answers and longer streaks score more. If you don't know it, the timer (or Skip) reveals the answer and releases the piece.

Play it: https://rinattzubeli.github.io/blockfall/

- Every flag gets its own original tune in its region's style, generated live in the browser with Web Audio: kalimba and djembe for Africa, oud and darbuka for the Middle East, sitar and tabla for South Asia, koto for East Asia, gamelan for Southeast Asia, fiddle jigs for Ireland and the UK, accordion waltzes for Western Europe, steel pan for the Caribbean, banjo for North America, ukulele for Oceania, and more.
- Voice input uses the browser's speech recognition (Chrome, Edge, Safari). Allow the microphone when asked. You can always type the answer instead.
- Controls: ← → move, ↑/X/Z rotate, ↓ soft drop, Space hard drop, C hold, T type answer, S skip, P pause, M mute, N music on/off. Touch buttons on phones.

Flag artwork from the open-source [flag-icons](https://github.com/lipis/flag-icons) set.
